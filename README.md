# My Python Projects

Small Python projects built from my phone using Termux.

## Projects

| File | What it does |
|------|--------------|
| `weather.py` | Shows live weather for any city |
| `weather2.py` | Same, with a colored table using rich |
| `todo.py` | To-do manager that saves tasks in a JSON file |

## How to run

1. Install Python in Termux: `pkg install python`
2. Install libraries: `pip install requests rich`
3. Run a project: `python todo.py`
